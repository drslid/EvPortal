Retour aux raccourcis

Votre écran. Vos raccourcis.

Touchez un raccourci pour ouvrir le service dans un nouvel onglet. Le bouton de thème en haut permet de choisir le mode clair ou sombre. Les huit langues sont disponibles dans les réglages ; l’arabe s’affiche de droite à gauche.

Organiser les raccourcis

« Tous » affiche d’abord les raccourcis les plus ouverts. À égalité, votre ordre manuel est conservé. Le classement reste enregistré après rechargement.

Dans une catégorie ou « Favoris », touchez « Modifier » puis déplacez les raccourcis avec leur poignée. L’étoile ajoute un favori et le crayon permet de modifier. Touchez « Terminer » quand vous avez fini. « Tous » conserve son classement automatique.

Au clavier, sélectionnez une poignée puis appuyez sur Espace, utilisez les flèches et validez avec Entrée. Échap annule.

Ajouter un raccourci ou une catégorie

Le bouton « + » ouvre le catalogue et propose de créer un raccourci ou une catégorie. « Déjà présent » indique un service déjà ajouté. La loupe recherche dans tous vos raccourcis.

Créez jusqu’à cinq catégories personnelles avec un nom de 16 caractères maximum et une icône au choix. Le crayon permet de les modifier. Les anciennes catégories dépassant ces limites sont conservées. Toutes les catégories restent visibles sans défilement horizontal.

Du téléphone à la Tesla

  1. Sur le téléphone, ouvrez EvPortal et préparez vos raccourcis.
  2. Touchez « Partager », nommez la sauvegarde puis créez le lien et le QR code.
  3. Conservez le code Telegra.ph affiché ou copiez le lien.
  4. Sur la Tesla, ouvrez Réglages → Importer depuis Telegra.ph et saisissez le code ou le lien.
  5. Chargez les raccourcis, vérifiez l’aperçu puis confirmez leur utilisation.

Le QR code se scanne avec un téléphone. Pour importer sur la Tesla, utilisez le code ou le lien.

Un partage est un instantané : après de nouvelles modifications, créez un nouveau partage et importez-le sur l’autre appareil. Il n’y a pas de synchronisation automatique.

La sauvegarde Telegra.ph est publique. « Mes liens partagés » retrouve les publications du compte présent dans ce navigateur. L’import accepte aussi les anciens liens et les fichiers JSON.

Plein écran Tesla

À l’arrêt, touchez « Plein écran ». Sur YouTube, choisissez « Accéder au site » ou « Go to site » pour revenir à EvPortal dans le mode Théâtre. Les raccourcis demandent un nouvel onglet, dont le comportement dépend du navigateur du véhicule.

Si la Tesla n’est pas reconnue, choisissez « Ouvrir le mode Théâtre Tesla » dans les réglages. Sur ordinateur, le bouton utilise le plein écran classique. La redirection peut évoluer avec les mises à jour du véhicule ou de YouTube.

L’ouverture d’un site ne garantit pas la lecture vidéo : pays, compte, abonnement et navigateur peuvent la limiter. Le divertissement s’utilise à l’arrêt.

Retrouver mes réglages

Vos raccourcis, favoris et préférences sont enregistrés dans ce navigateur. Les anciennes configurations sont reprises sur la même adresse. Le navigateur et le Théâtre peuvent avoir des stockages distincts ; importez votre partage dans chacun. Effacer les données du site nécessite une restauration depuis un partage ou un fichier JSON.

Tester un aperçu local

Le téléphone et la Tesla doivent pouvoir accéder au même aperçu. « localhost » désigne chaque appareil séparément. Dans « Adresse d’EvPortal », renseignez une adresse joignable depuis les appareils concernés. L’adresse publique affiche la version publiée, qui peut différer de cet aperçu.

À propos et confidentialité

EvPortal est gratuit, sans affiliation avec Tesla. Logos et traductions sont embarqués. Les compteurs d’ouvertures restent dans votre configuration, sans outil d’analyse d’audience. Telegra.ph est contacté à votre demande ; le jeton du compte reste séparé du partage. Les sites ouverts appliquent leur propre politique.

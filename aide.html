Retour aux raccourcis

Votre écran. Vos raccourcis.

Touchez un raccourci pour ouvrir le service dans un nouvel onglet. Le bouton de thème en haut permet de choisir le mode clair ou sombre. Les huit langues sont disponibles dans Paramètres, avec leurs noms et drapeaux ; l’arabe s’affiche de droite à gauche.

Organiser les raccourcis

« Tous » affiche d’abord les raccourcis les plus ouverts. À égalité, votre ordre manuel est conservé. Le classement reste enregistré après rechargement.

Dans une catégorie ou « Favoris », touchez « Modifier » puis déplacez les raccourcis avec leur poignée. L’étoile ajoute un favori et le crayon permet de modifier. Touchez « Terminer » quand vous avez fini. « Tous » conserve son classement automatique.

Au clavier, sélectionnez une poignée puis appuyez sur Espace, utilisez les flèches et validez avec Entrée. Échap annule.

Ajouter un raccourci ou une catégorie

Le bouton « + » ouvre le catalogue et propose de créer un raccourci ou une catégorie. « Déjà présent » indique un service déjà ajouté. La loupe recherche dans tous vos raccourcis.

Créez jusqu’à cinq catégories personnelles avec un nom de 16 caractères maximum et une icône au choix. Le crayon permet de les modifier. Les anciennes catégories dépassant ces limites sont conservées. Les catégories affichées se répartissent sans défilement horizontal.

Un service peut apparaître dans plusieurs catégories avec un seul favori et un seul compteur ; Tous ne l’affiche qu’une fois. Dans Modifier, ouvrez Autres catégories pour choisir où il apparaît. Supprimer une catégorie conserve les services encore présents dans une autre catégorie.

Choisir son catalogue et son accueil

Dans Paramètres → Catalogue et accueil, choisissez votre pays, les catégories à afficher et l’ouverture sur vos favoris. Le pays adapte les suggestions dans Ajouter ; il ne supprime pas vos raccourcis. Voir tous les pays élargit le catalogue. Une catégorie masquée conserve ses raccourcis dans Tous et Favoris. Ces choix restent sur cet appareil et ne sont pas transmis dans les sauvegardes ou par QR. Le pays initial est suggéré par la région du navigateur, sans demander votre position.

Téléphone : envoyer ou recevoir

  1. Dans Paramètres → Téléphone, choisissez Envoyer ou Recevoir.
  2. Scannez le QR affiché avec votre téléphone.
  3. Pour envoyer depuis le téléphone, choisissez ses raccourcis ou une sauvegarde, puis touchez Envoyer.
  4. Sur l’écran qui reçoit, touchez Ajouter pour conserver la sauvegarde sur cet appareil.
  5. Pour utiliser son contenu, ouvrez Mes sauvegardes → Restaurer.

Le QR sert au transfert avec le téléphone. Créer un code ou un lien n’affiche pas de QR.

Le transfert est chiffré et valable cinq minutes lorsque le service est disponible. Il transmet un instantané, sans synchronisation automatique. Recevoir une sauvegarde ne remplace pas vos raccourcis.

Code ou lien

Dans Paramètres → Code ou lien, Créer prépare un code et un lien EvPortal à copier. Ajouter accepte l’un ou l’autre et enregistre une copie locale après validation. Les fichiers JSON restent disponibles dans Plus d’options. La page Telegra.ph créée est publique ; la copie locale et la page en ligne sont distinctes.

Plein écran Tesla

À l’arrêt, touchez « Plein écran ». Sur YouTube, choisissez « Accéder au site » ou « Go to site » pour revenir à EvPortal dans le mode Théâtre. Les raccourcis demandent un nouvel onglet, dont le comportement dépend du navigateur du véhicule.

Si la Tesla n’est pas reconnue, choisissez « Ouvrir le mode Théâtre Tesla » dans Paramètres. Sur ordinateur, le bouton utilise le plein écran classique. La redirection peut évoluer avec les mises à jour du véhicule ou de YouTube.

L’ouverture d’un site ne garantit pas la lecture vidéo : pays, compte, abonnement et navigateur peuvent la limiter. Le divertissement s’utilise à l’arrêt.

Restaurer une sauvegarde

Dans Paramètres → Mes sauvegardes → Restaurer, choisissez une sauvegarde dans Sur cet appareil ou En ligne, puis vérifiez son contenu. Seul Restaurer remplace vos raccourcis. Les options des paramètres permettent d’annuler la dernière restauration. Ajouter un code, un lien, un fichier ou une réception QR conserve une sauvegarde sans l’appliquer. Chaque navigateur conserve sa propre liste locale.

Tester un aperçu local

Le QR utilise l’adresse du portail ouvert. Sur un téléphone, localhost ou 127.0.0.1 désigne le téléphone lui-même. Pour un essai entre appareils, le portail et le relais doivent être accessibles aux deux en HTTPS. Les codes et liens de sauvegarde utilisent l’adresse publique d’EvPortal.
